# ENTRENÓS Store — Landing Page estilo editorial

Landing page estática em HTML, CSS e JavaScript puro.

## Como usar

1. Abra `index.html` no navegador.
2. Troque o número do WhatsApp em `script.js`:

```js
const WHATSAPP_NUMBER = "5511999999999";
```

Use o formato: DDI + DDD + número. Exemplo: `5511988887777`.

## Como trocar os mockups

Substitua os arquivos da pasta `assets` mantendo os mesmos nomes ou altere os caminhos no `index.html`.

Principais imagens:

- `assets/camiseta-classica.svg`
- `assets/camiseta-resenha.svg`
- `assets/camiseta-frases.svg`
- `assets/camiseta-minimal.svg`
- `assets/modelo-camiseta.png`
- `assets/logo-mascotes.png`

## Observação de direção visual

O layout usa uma linguagem editorial esportiva: tipografia gigante, contraste forte, cards de produto, hero de impacto e CTAs diretos para WhatsApp. Não é uma cópia de nenhuma marca; é uma interpretação visual adaptada para a ENTRENÓS Store.
